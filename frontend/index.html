The Pipeline

How It Works

Every document passes through four independent analysis layers. Each layer catches different types of forgery — together they form a comprehensive verification that no single check could achieve alone.

Visual Forensics

Dual-branch CNN analyzes spatial and frequency-domain features to detect pixel-level manipulation, blur, noise, splicing, and affine warps.

OCR / Text Consistency

Extracts text and validates official headers, names, and dates against expected templates using fuzzy matching — catches spelling errors and swapped text.

Document Structure

Validates format compliance — Aadhaar number length, PAN regex pattern, and required field presence. Format-valid does not mean government-verified.

Layout Consistency

Checks that extracted text fields fall within calibrated template regions. Misplaced or missing fields trigger layout risk flags.
